# Gun Bow Skins - Fabric client mod, Minecraft 26.3
Re-skins the bow as 48 real-world firearms (3D models, cosmetic only).
Keys: K = open the gun menu, G next skin, H previous skin, J vanilla bow.

## Use on GitHub
1. New repo -> upload ALL these files (keep the folder layout) -> commit.
2. Actions tab -> "Build mod" -> when green, download artifacts:
   - gunbow-jar            -> put the .jar in .minecraft/mods (needs Fabric Loader + Fabric API 26.3)
   - gunbow-resourcepacks  -> works with NO mod: unzip, put one zip in .minecraft/resourcepacks, enable it in Options > Resource Packs
The 3D models are generated by gen.py during the build.
